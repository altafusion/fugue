## Headings and Text

Write body copy in **sentence case**. Use **Title Case** for page titles, sidebar labels, and section headings (`##`–`######`).

| Style | Syntax | Result |
| ----- | ------ | ------ |
| Bold | `**bold**` | **bold** |
| Italic | `*italic*` | *italic* |
| Code | `` `inline` `` | `inline` |

---

## Lists

Ordered and unordered lists work as usual:

1. Add a new file under **`content/`** (for example **`3.guide.md`**).
2. Set frontmatter **`title`** and optional **`navigation.icon`**.
3. Link to it from the landing page or other docs.
