This site is a **documentation starter** built with **`docus`** + **Nuxt Studio** on the [Docus](https://docus.dev) theme. Use **`templates/docus-site`** in the monorepo, copy to **`apps/<name>/`**, or extract to a standalone repo — see **`README.md`**.

---

## What You Get

| Piece | Purpose |
| ----- | ------- |
| **Landing page** (`content/index.md`) | Hero with links into your docs |
| **Markdown docs** (`content/*.md`) | Sidebar navigation and full-text search |
| **Read gate** | Optional access key via `{PREFIX}_ACCESS_KEY` |
| **Nuxt Studio** | Edit and publish content when OAuth and GitHub are configured |

The default dev port in the monorepo is **8002**. Run **`pnpm dev`** from this folder (or **`pnpm --filter @altafusion/docus-site-template dev`** from the repo root).

---

## Customize This Site

1. **`nuxt.config.ts`** — set `site.name`, `auth.envPrefix`, and `studio.repository` for your org/repo.
2. **`app/app.config.ts`** — favicon path and UI chrome (GitHub links stay hidden for Studio-only repos).
3. **`content/**`** — replace the sample pages with your documentation tree.
4. **`.env`** — copy from **`.env.example`**; set `MY_DOCS_ACCESS_KEY` for local read access when auth is enabled.

::tip
In local dev, open **`/login`** and use **Edit Content** in the header when Studio is configured — not bare **`/_studio`**.
::
