First public release of `@altafusion/fugue-devtools`, the dockable debugger drawer (qetools). It opens with `?devtools`, or with the params a site sets in `openParams`. The persist helpers and the storage code they use now live inside this package, under `@altafusion/fugue-devtools/persist`, and `@altafusion/fugue-devtools-persist` is gone.
